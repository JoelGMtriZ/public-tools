# public-tools

A collection of standalone tools and utilities, each self-contained in its own
folder with its own README, license, and dependencies.

## Tools

| Tool | What it does |
|------|--------------|
| [**bastion**](bastion/) | Offensive reconnaissance mapper for authorized web-app assessments, network pentests, and bug-bounty hunting. Folds recon observations into assets, reads them for leads, and ranks the leads into avenues of approach. Passive by default; active probing is gated behind a scope file. |
| [**Claude_usage_audit**](Claude_usage_audit/) | Local, zero-dependency tool that turns a claude.ai data export into a per-conversation token report, showing where chat tokens go and which threads to split. |

Each tool is independent — see its folder's README for install and usage.
